# 1. アプリ概要

目的：文字にアウトライン風（縁取り）効果を与える CSS の text-shadow プロパティを簡単に計算・取得
主な利用者：デザイナーやフロントエンドエンジニア

# 2. MVP（必須機能）

- テキスト入力フォーム（リアルタイムプレビュー用）
- ストローク幅（縁取りの太さ）指定フォーム
- 縁取りカラー選択（<input type="color">）
- プレビュー領域への即時反映（背景色：ライト／ダーク切り替え）
- 生成された CSS text-shadow の文字列を表示＋「コピー」ボタン（navigator.clipboard.writeText）

# 3. コア機能

- プリセットのローカルストレージ保存・読み込み・削除（複数管理）
- 多重シャドウ、内側シャドウ、グロー効果の組み合わせ
- 出力フォーマット切り替え（インラインスタイル／CSS クラス／SCSS 変数）
- URL パラメータによるプリセット共有

# 4. UI/UX 要件

- レイアウト：左側に設定パネル（アコーディオン式）、右側にプレビュー＋コード表示
- 上部にアプリタイトルと背景色切り替えボタン
- アクセシビリティ：キーボード操作、aria ラベル、コントラスト比
- レスポンシブ対応（PC／スマホ）

# 5. 技術スタック

- フレームワーク：React + TypeScript + Vite
- 状態管理：React Context
- スタイリング：Tailwind CSS
- コンポーネントライブラリ：shadcn/ui
